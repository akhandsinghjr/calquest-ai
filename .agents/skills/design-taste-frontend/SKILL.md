# Design Taste Frontend Skill (Leonxlnx/taste-skill)

## Three Dials Configuration
- `DESIGN_VARIANCE`: 7 (Asymmetric Bento hierarchy & ledger-style data grouping)
- `MOTION_INTENSITY`: 7 (Spring-physics transitions, layoutId shared element pills, tactile press states)
- `VISUAL_DENSITY`: 6 (Balanced Material 3 Expressive tonal containers & clean negative space)

## Strict Rules
1. **No Emojis**: Never use Unicode emojis anywhere in the interface. Use crisp vector icons (`lucide-react`) inside tonal containers.
2. **Typography**: Never use generic `Inter`, `Roboto`, or `Arial`. Use `Plus Jakarta Sans` for display/headings (`tracking-tight`), `DM Sans` for body copy, and `JetBrains Mono` (`tabular-nums`) for all numerical metrics.
3. **Material 3 Expressive Tonal Surfaces**: Replace harsh gray borders and neon glows with tonal surface hierarchy (`#0B0D0E` surface dim, `#13171A` container low, `#191F24` container high, `#102B22` primary container) and subtle `border-white/[0.07]` hairlines.
4. **Spring Physics Motion**: Never use linear easing. Use spring physics (`stiffness: 380, damping: 30`) and shared `layoutId` pills for segmented controls and navigation.
